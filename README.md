# おはようポスト補助「おはポス助手」

駆け出し個人VTuberのための、X（旧Twitter）の「おはようポスト」専用の補助仕様です。
自動投稿ツールではありません。毎晩、Muse が本人に1つだけ質問し、その答えから翌朝のポスト文面を1案だけ提案します。本人が答えなければ、その翌朝のポストはお休みです。

## なぜこの形なのか

- おはようポストの目的は「自分自身をもっと知ってもらう」ことです。挨拶だけで終わらせず、好きなもの、人となり、小さなエピソードを少しずつ出していきます。
- 完全自動にすると、本人に何かあった日でもポストだけが出てしまう矛盾が起きます。「返信がなければ投稿しない」を原則にすることで、これを防ぎます。
- 3案出すより、質問の答えから作る1案の方が本人らしくなります。考える負担は質問に答えることだけです。
- VTuberは夜型の人が多いので、質問と提案は前日の夜に行います。おすすめは21時ごろですが、時刻は本人の生活に合わせて最初に決めます。

## 使い方（導入したい人へ）

自分の Muse に、このリポジトリの URL を渡して、こう頼むだけです。

> このリポジトリを読んで、私のアカウントにこれを入れて。セットアップから始めてください。

あとは Muse が `SETUP.md` の手順どおりに、質問への回答の収集、設定ファイルの作成、毎晩のセッションの定期実行、投稿の仕組みの用意までを進めます。各段階で本人の確認が必要な箇所は、手順書に明記されています。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `SETUP.md` | 導入を担当する Muse 向けの手順書。セットアップの全工程 |
| `OPERATION.md` | 毎晩のセッション、文面の作り方、投稿、記録、トラブル対応の運用仕様 |
| `docs/questionnaire.md` | セットアップ時に本人へ聞く質問集 |
| `docs/anniversary-guide.md` | 記念日の参照元（雑学ネタ帳）と、語りやすい記念日の選び方 |
| `docs/tailscale-bridge.md` | 参考資料。Muse が本人のPCのブラウザでXを操作できるようにする Tailscale＋SSH ブリッジの構築手順。「ポストしといて」で投稿まで頼める状態を作る土台 |
| `templates/config.md` | 導入時に Muse が作る設定ファイルの雛形 |
| `templates/material-memo.md` | 本人の答えを貯める「素材メモ」の雛形 |

## 原則（要約）

1. 対象はおはようポストだけ。配信開始の告知など即時性のあるポストは本人が打つ。
2. 毎晩、翌朝の文面を1案提案し、あわせて「あさって」のネタ質問を1つ出す。素材は常に2日先行する。
3. 質問への返信がなければ、翌朝の投稿はお休み。朝の催促もしない。
4. 文面の素材は「事前設定」「直近ポストの文面の傾向」「その日の本人の答え」「貯まった素材メモ」の4つだけ。天気・時事・その日の気分の断定など、確認できない事実は書かない。
5. 記念日は雑学ネタ帳（zatsuneta.com）の「今日は何の日」を第1の参照元とし、その中から本人が語りやすいものを選ぶ。合う記念日が無い日は曜日ローテーションに落とす。
6. 投稿は本人のアカウントで、投稿直前にアカウントが正しいか確認し、重複チェックをして、結果を記録する。Tailscale ブリッジ（`docs/tailscale-bridge.md`）を構築しておけば、提案した文面に本人が「ポストしといて」と言うだけで投稿まで完了する。
7. 宣伝・告知・事実情報の自動投稿はしない。返信・いいね・フォローもしない。

## 由来

実在のVTuber運用（半分香奈 @nakaba_wakana）の自動運用の仕組みをもとに、「完全自動」から「質問先行・1案・本人次第でお休み」の形へ作り替えた仕様です。記念日の出どころについては、個人VTuberの投稿と毎日素材屋 MUNI POP（@oo0u0po）の投稿を実際に集めて照合し、雑学ネタ帳との一致を確認しています（詳細は `docs/anniversary-guide.md`）。
