# 記念日の参照元と選び方

## 参照元

記念日の第1の参照元は **雑学ネタ帳（zatsuneta.com）の「今日は何の日」** です。

- 月別一覧：`https://zatsuneta.com/category/anniversary{月}.html`（例：11月は anniversary11.html）
- 日付別のページと、記念日ごとの個別記事があります。対象日の一覧を取得し、その中から選びます。
- 記念日の名称は、原則として雑学ネタ帳に載っている正式な名称を使います。

### なぜ雑学ネタ帳なのか（調査の要約）

2026年11月に、実際に使われている記念日ポストを集めて照合しました。

- 個人VTuberの記念日ポスト13日分・延べ22件は、雑学ネタ帳の同じ日付の一覧に22件すべて載っていました。同じ記念日を複数のVTuberが同じ日に使う例も複数ありました（紅茶の日、ポッキー＆プリッツの日、レンコンの日、任天堂の日など）。
- 毎日おはV素材を投稿する素材屋 MUNI POP（@oo0u0po）の素材23件では、テーマとしては23件中22件が雑学ネタ帳の同日ラインナップと一致しました。ただし素材のタイトルでは名称を短くする例があり（例：「人生100年時代の日」→「人生100年記念日」、「いい靴の日」→「靴の日」）、文字列の完全一致は15件でした。名称は正式名を使うのが安全です。
- 日本記念日協会のデータベースは認定記念日だけで、VTuberがよく使う非公式の記念日（任天堂の日など）が欠けます。Wikipediaの記念日一覧もカバー率が低めでした。統合して一覧化している雑学ネタ帳が、実態に一番近い参照元です。

## 選び方：活動者が語りやすいものを選ぶ

その日の一覧から、質問にしやすく本人が語りやすい記念日を1つ選びます。優先順位は次のとおりです。

1. **本人の設定・好みに合うもの**：設定ファイルの好きなもの、モチーフ、活動内容に直接つながる記念日（例：ココア好きな人の「ココアの日」）。
2. **答えが返ってきやすいテーマ**：食べ物・飲み物、季節もの、関係性もの（友達、夫婦、推し、家族）は、好き嫌いや思い出を一言で答えられます。素材屋の実例でもこの系統が中心でした。
3. **語呂合わせで覚えやすいもの**：11月の「いい〇〇の日」のような語呂合わせ系は、読み手にも伝わりやすく、問いかけにしやすいです。
4. **二十四節気などの季節の節目**：立冬・小雪なども「寒さ対策は？」のように質問化できます。

避けるもの：

- 由来や意味を説明しないと伝わらない、専門的すぎる記念日
- 災害・事故・病気など、軽い朝の挨拶に合わない重いテーマ
- 特定の商品やブランドの宣伝に寄りすぎるもの（本人が好きだと設定にある場合は除く）
- 本人の設定と矛盾するもの（苦手なものの記念日を「好きですか」と聞く等。ただし「実は苦手」という自己開示の質問にするなら可）

## 質問の作り方

選んだ記念日は、そのまま質問にします。

- 基本形：「あさっては〇〇の日です。〇〇は好きですか？」＋選択肢（好き／ふつう／実は苦手）＋一言自由
- 本人の答えが文面の核になります。本人が「好き」と答えたら、その理由や一番好きな種類まで一言で聞けると、文面が具体的になります。
- 記念日の説明は文面に長く書きません。「今日は〇〇の日なんだって」程度に留め、主役は本人の答えです。

## 合う記念日が無い日

無理に記念日に寄せず、`OPERATION.md` の曜日ローテーションの型（好きなものの深掘り、実はこんな人、二択、ルーティン等）から質問を作ります。記念日は割り込みであって、必須ではありません。
