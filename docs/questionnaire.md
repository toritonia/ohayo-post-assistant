# セットアップ質問集

導入の第1段階で本人に聞く質問です。選択式を中心にし、答えにくい質問には「まだ決まっていない」を必ず用意します。必須10問が揃えば運用を始められます。残りは後から足せます。

## 必須10問

1. **対象アカウント**：おはようポストを出すXアカウント（@〜）はどれですか。
2. **提案の時刻**：毎晩のセッションは何時がいいですか。おすすめは前日の21時です。配信前・配信後など、生活に合う時刻を選んでください。
3. **投稿の時刻**：おはようポストは朝何時ごろに出したいですか。
4. **名前と読み**：活動名と、その読み方を教えてください。
5. **自分だけの挨拶**：おはようの代わりに使う、自分だけの挨拶はありますか（無い場合は「まだ決まっていない」）。
6. **口調のサンプル**：次の3文から、一番自分に近い口調を選んでください（丁寧め／ふつうのタメ口／柔らかいタメ口）。または、自分の過去ポストから近いものを1つ挙げてください。
7. **絵文字・顔文字**：よく使う絵文字や顔文字はありますか。濃さは「多め／ふつう／少なめ」のどれですか。
8. **推しマークとファンネーム**：ファンマーク（推しマーク）と、ファンの呼び名は決まっていますか。
9. **定番ハッシュタグ**：おはようポストに付ける定番のタグはありますか（例：#おはようVtuber、自分の名前のタグ、ファンアートタグ等）。
10. **好きなもの3つ**：好きなものを、理由とセットで3つ教えてください（食べ物、飲み物、音楽、ゲームなど何でも）。

## あると文面が本人らしくなる質問

11. **苦手なもの・弱点**：苦手なことや、ちょっとした弱点はありますか。
12. **ギャップ**：見た目や第一印象と、中身で違うところはありますか。
13. **エピソード在庫**：小さい失敗談や笑えるエピソードを、思いつく範囲で教えてください（最低5つあると文面の幅が出ます。実話でも、キャラクター設定として決めた話でも構いません。その区別も教えてください）。
14. **見た目の推しポイント**：自分の姿で気に入っているところを3つ教えてください。
15. **名前やモチーフの由来**：名前の由来、モチーフ（動物、色、アイテム等）とその理由はありますか。
16. **ルーティン**：朝起きて最初にすること、夜寝る前の習慣はありますか。
17. **活動のこと**：主な活動（配信内容、投稿するもの）と、配信や活動の曜日パターンはありますか。おはようポストで触れてよい範囲も教えてください。
18. **言ってはいけない表現**：使われたくない言葉、触れてほしくない話題はありますか。
19. **読み手との約束**：フォロワーに言っておきたい約束や決め台詞はありますか（例：「ここは帰ってこられる場所」等）。

## 聞き方のコツ（Muse 向け）

- 一度に全部聞かず、必須10問を先に終えます。
- 選択式にできるものは選択式にし、自由記述は短くて済む形にします。
- 「まだ決まっていない」は未定リストにまとめ、設定ファイルに残します。未定は欠陥ではなく、活動しながら決まっていくものです。
- 答えは要約しすぎず、本人の言葉のまま設定ファイルと素材メモに残します。
